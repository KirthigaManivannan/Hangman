# Break Room Hangman

A multiplayer hangman game. Everyone plays on their own phone or laptop.

## Run it

1. Install Node.js from https://nodejs.org
2. In this folder, run: node server.js
3. Open http://localhost:3000

## How to play

- Pick your name and join.
- The host starts the game.
- One player types a secret word. Everyone else guesses letters.
- Wrong guess? Others can throw a tomato 🍅 or an egg 🥚 at you.
- Press END GAME to see the winner.
